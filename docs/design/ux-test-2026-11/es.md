# ES report: character art and the animation studio (as returned by the tester)

Counts: S1 0, S2 10, S3 11, plus 1 known note. Scripts s01..s30, 70 screenshots and test PSDs are in scratchpad/ux/es (paths below relative to it).

## Scope
Project `sample` copy. Viewports 1280x800 (main), 1440x900, 1920x1080, 900x700, plus 1000x600, 1280x720 and 390x780 for resizing with the studio open. Characters in the Files panel: mina and robo. Alice (flat PNGs, no rig.json) has no row (ES-22, known).
Covered: all 8 tasks. Discovery via Files panel, `#` and `>` palette, F12/right-click/hover on an `animate` line, and the `studio.html` landing page. Animate workflow including gizmo, Auto-key, Key, key select, ease, key drag, Length, undo/redo, Apply, Close guard, Try in scene. Parameters, pad, poses. Model mode. Physics, Reactions, Warp, Mask and Frames (discoverability only). PSD upload with a copy of mina.psd as `lena.psd`, a hand-made PSD with Photoshop-default names (`oddnames.psd`) and a corrupt `broken.psd`, plus Reconvert. Docking. 10 open/close cycles, rAF sampling, contrast and Tab order.
Not covered: standalone page past its landing screen (folder picker cannot be driven headless), Export..., free-mesh and mask/warp point editing, touch, Electron Studio.
Caveat: kit runs the dev server with `--no-art`, so conversion did not start by itself after an upload; palette "Reconvert All Art" was used. The automatic converter was not seen. Headless rAF is capped near 165 Hz, so only relative frame numbers mean anything.

## What worked well
- Files panel open is two clicks and 70-150 ms; repeated and rapid open/close is clean (no leaked frames, no page errors); focus returns to the editor.
- Stage click and tree row drive each other; choosing an animation selects the part it keys; stage left edge and width stay put between Model and Animate.
- F12 on an `animate` line opens the studio on that animation with scene backdrop and Try in scene; Place in scene's Copy puts the exact `show` line on the clipboard.
- Keying is forgiving: Auto-key on/off with a clear hint, typed values key at the playhead, every ◆ makes a visible parameter lane, undo steps are small, Ctrl+Z, Ctrl+Y and Ctrl+Shift+Z all work.
- Apply and Save-as-pose say what happens next; the Close guard exists.
- Model mode explains itself (Keyforms guidance text, persistent "Done picking" state, a note when parameters are off rest).
- The converter's Output text is concrete and opens by itself on Reconvert.
- Keyboard groundwork: focus trapped in the dialog, logical Tab order, aria-labels and Alt/arrow alternatives on grips, tooltips with key letters on tools.
- Layout holds at 1280x800, 1440x900, 1920x1080, 900x700, 1280x720, 390x780: no document scroll bars, no nested scrollers, no studio console errors (only the AudioContext notice and one unrelated 404).
- Performance: looping `dance`, rAF median 6.1 ms (p95 6.2, max 6.2) in both the studio page and the stage frame, same as the idle editor.
