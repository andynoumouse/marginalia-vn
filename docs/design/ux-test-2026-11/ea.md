## Findings
EA-1 · S2 · bug · Narration ending in punctuation gets a doubled closing quote, and the error never mentions quotes. Steps (s06-quote-trace.mjs, s05-author-full.mjs): on a new indented line type `"A rainy evening at the station."` char by char (12 to 200 ms per key). Expected: the auto-closed `"` is overtyped, one pair (works for `"Hello"`, `"Hello, world"`, `"It is 5"`, `"a.b"`, `"A: b"`, `"Sit down":`). Actual: line becomes `"A rainy evening at the station.""`. Happens whenever the char before the closing quote is not a letter or digit: `.` `!` `?` `;` `)` `-` `...` all doubled (12 of 21 variants), i.e. most narration lines. In an 18-line run the stray quote ended on the last line (`end"`), reported as `Unknown command "end""`. Diagnostics: `"The rain falls.""` gives `Unknown command "The rain falls."`; an unclosed `"The rain falls.` gives `Unknown command ""The"` (s11). Neither says "quote". Evidence shots/01-full-story.png. Reproduced many times. Known: no.

EA-2 · S2 · bug · Shift+F8 does not go to the previous problem; F8 shows no message. s13-shiftf8.mjs: 5 problems at lines 6 (warning), 7 (error), 8 (warning), 10 (error), 11 (error). Shift+F8 from line 9 goes to 10 (below), from 5 goes to 7, from 13 goes to 8. Cause: Shift+F8 is Monaco's `editor.action.marker.prevInFiles` (editor/commands.ts), ordered errors before warnings; F8 is the custom `nextProblem` (editor/editor.ts), ordered by position, so not inverses. F8 lands on the problem but shows no message (only hover); Shift+F8 opens Monaco's message peek, so the keys also look different. Evidence shots/01-shiftf8.png, 01-f8-widget.png. Reproduced three times in s13 and again in s12. Known: no.

EA-3 · S2 · bug · Accepting a text-tag completion after `{` leaves a stray `}`. s35-tags.mjs: type `hero: Hi {` (auto-closes to `{}`, offers 11 tags), Enter on `i`. Also `{col` then Tab. Expected `{i}|{/i}`. Actual `hero: Hi {i}{/i}}` and `{color=#ff6fa5}{/color}}`. `[` then Enter gives a correct `[trust]`. Reproduced twice. Known: no.

EA-4 · S2 · usability · Follow preview (default on) pulls the editor away from the line you are typing at, on every autosave. s37-follow-yank.mjs (branching template, 1280x720, 99-line script): click editor, Ctrl+End, type `# my note`. About 0.5 s later (autosave, preview reload) the view jumps from lines 79-99 to 24-45 (the preview's line), cursor off screen. Same cause at first look: a long script opens scrolled to the preview line (view 24-45, cursor on line 1), hiding the welcome comment (shots/01-branching-1280.png). Reproduced twice. Known: no.

EA-5 · S2 · usability · Syntax slips are reported as `Unknown command "..."` or a bare unexpected character, with cascades (s11-diagnostics.mjs, s26-trailing-comments.mjs):
- `label start` -> `Unknown command "label"`, `Unexpected indentation`, warning `No labels found; nothing to play` (wanted: "label needs a colon")
- `if trust >= 1` / `menu` / `else` (no colon) -> `Unknown command "if"` etc., plus 1-3 `Unexpected indentation` / `Options only belong inside a "menu:" block` (wanted: "add a colon")
- `hero "Hello there."` -> `Unknown command "hero"` though hero is defined (wanted: "dialogue is `hero: text`")
- `$ trust = 1` -> `Unknown command "$"` (wanted: "use `set`")
- `set trust =` / `set trust 1` -> `Unknown command "set"` (wanted: "set needs `name = value`")
- `set trust == 1`, `if trust = 1:` -> `Unexpected character "="` (wanted: "`=` assigns, `==` compares")
- `scene bg_title # park` -> `Unexpected "#" in scene (transitions: ...)` (wanted: "comments need their own line")
Good messages: `Unknown command "shwo" (did you mean "show"?)`, `Unknown label "benchh" (did you mean "bench"?)`, `Unknown character "bob" (add a define line)`, `Expected an indented block after this line`, `Use spaces for indentation, not tabs`, `Label "start" is defined twice`. Reproduced. Known: no (TODO.md only lists did-you-mean for game.json and rig.json).

## What worked well
- Completions fast (70-230 ms) and project-aware: backgrounds, labels, characters, variables, text tags, `define` options. A newly added background shows up immediately.
- Did-you-mean works for commands, labels, characters and backgrounds. Ctrl+. applies with one Enter, lightbulb on the squiggle line, squiggle hover shows "Quick Fix... (Ctrl+.)".
- Live loop quick and safe: Ctrl+Enter shows the line in 160 ms (also inside an `if`); preview returns to your line after reload; no data loss in any edge case (undo past a save restores disk, closing a tab right after typing saves, 3001-line paste reloads in under 1 s, 6966-char line fine).
- Preview error banner is explicit and the game keeps playing the last good version. Invalid game.json never written.
- Variables panel live, double-click edits, tooltip lists accepted forms.
- Palette modes (`@`, `:`, `#`, `?`, create-on-miss) discoverable; `@ben` then Enter jumps.
- F2 renames a label or variable across all references as one undo step. Find in Files has whole word, case, regexp with `$1`, inline regexp error, one Ctrl+Z undoes Replace all.
- F1 opens at the topic for the line under the cursor; reference can move to its own window.
- Alt+1/2/3 work from anywhere including inside the preview, with a status hint. Ctrl+P and F1 also work from the preview.
- Deleting a script asks first and offers Undo. Duplicate localization ids are flagged.
- Preview already running on first open, so a newcomer sees a result before touching anything.
