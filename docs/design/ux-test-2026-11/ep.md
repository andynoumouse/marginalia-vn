## What worked well
- Rename/move: references follow in every script and game.json, the open editor shows the new text at once, one undo step per file, a moved script keeps its tab.
- Delete: confirm names the target and where it goes, folders show their file count, Esc cancels, toast has Undo, Restore from Trash lists entries with ages, Undo of Replace works and is itself undoable.
- Asset viewer: 25 ms, Left/Right wrap, Esc returns focus to the row, font sample works.
- Drop results are specific: sanitised final names (`My_Cool_Sound.ogg`), accepted-type list for `.txt`/`.exe`, "exists" refusals, PSD rule message, mixed batches report both lists, errors stay until dismissed.
- Context menus: complete per row kind, Shift+F10 and ContextMenu key work, arrows skip separators, disabled items carry a reason.
- Git: branch and change count at the top, specific LFS and `.gitignore` warnings, one-click "Add to .gitignore", Ctrl+Enter commits in 1.5 s.
- Build: checks in tens of ms, errors block with a tooltip and a link to the exact line, warnings gate behind a tick that resets on re-run, export in 0.56 s with file count and size, "Open the game" link works and the export reaches the title screen.
- game.json: value messages list valid values, hover help names Ctrl+Enter, edits reach the preview in ~1.5 s, invalid JSON is marked and left unsaved.
- Translate: unfilled boxes obvious, edits save as you type, source-changed tracking and CSV export work; Voice empty state offers two routes.
- Playtest and Statistics output readable and fast; Reset Player Data and Empty Trash ask first; section folding persists.
