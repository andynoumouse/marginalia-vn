## Findings
OB-1 · S1 · docs · `vn init` crashes on a fresh clone. Steps: copy `bin/`, `tools/` and `package.json` (what a clone has; `dist/` is gitignored) and run `node bin/vn.mjs init ../x`. Expected a project. Actual `ERR_MODULE_NOT_FOUND ...dist/engine/src/index.js`, a raw stack trace. `npm install` does not build (no `prepare` or `postinstall`). Tutorial ch.1 "From the command line" and README "Start your own game" give no clone, `npm install` or build step for the engine; only README Quick start's `npm run dev` builds it. Evidence: reproduced once, deterministic (missing-file import). bin/vn.mjs line 83. Known: no. (TO VERIFY by coordinator.)

OB-2 · S2 · docs · Ch.2 snippets don't form a working story. Doc never says where the "Who is he?" menu goes, and `label stranger` never appears; the doc's own Outline picture (start, bench, stranger, train, endings) can't be reproduced (tester's showed bench and chat). `call chat("Mina", 1)` has no location; without it `stay_ending` is unreachable and playtest reports it, plus `bonus` "read but never set". `jump train` is never given; it works only because a label falls through into the next label in file order (Outline's dotted "runs on" arrow), never explained. Ch.1 says to delete everything below the `define` lines, which removes the template's `set kindness = 0`. Ch.2 says `warmth` "was created at the top of the file" but never says to add `set warmth = 0`; nothing complains, so it fails silently. The "finished versions" of other endings are in `games/tutorial/`, which Studio and online readers don't have. Also missing from the doc but present in the finished game: `show ren`, `move`, `shake`, `sound play thunder duck`, `jump stranger`. Evidence s4-ch2.mjs, shots/01-ch2-playtest-literal.png, 03-ch2-outline.png. Reproduced twice (s4, s13). Known: no.

## What worked well
- Edit, save, see it: ~2 s reload that keeps your line, with a clear "saved" state.
- Error messages and fixes: "Unknown command (did you mean "show"?)" plus a Ctrl+. quick fix, exactly as documented.
- Ctrl+P prefixes `@ : # >`; F1 opens the reference in a modal at the right topic.
- Outline (draws call and run-on arrows), live Variables panel with editable values, playtest report with clickable lines, Build dialog with its gated "I've seen these warnings" box.
- An asset drop reports exactly where the file landed. Duplicate JSON keys are flagged.
- Build/export fast (5 s) and the output loads from any static server.
- Pasted doc text works as written; the docs' internal links, images and anchors are all valid.
- `vn init` error messages are helpful (e.g. "Unknown template "foo" (blank, classic-adv, ...)").
